# v1.0 RAG — Runtime Verification

> 一次以**外部 OpenAI-compatible Provider** 完成的 v1.0 RAG 端到端驗證紀錄。
> 本文件不含 API key、Authorization header、完整 prompt 或私人路徑。
> 語言：繁體中文。v1.2 Agent 的對應驗收見 [v1.2-runtime-acceptance.md](v1.2-runtime-acceptance.md)。

## Purpose

驗證 v1.0 的 RAG 主路徑在**真實 Provider** 下能端到端跑通，且三種行為都符合設計：

1. 有足夠證據時 → 模型實際回答，且 Citation 有效、Sources 由後端組裝。
2. 完全無關的問題 → **第一層 Threshold 前置拒答**，不呼叫 LLM。
3. 文件中不存在的事實 → 拒答，且不猜測。

## Verified Environment

```text
Verified provider: Groq OpenAI-compatible API
Verified model:    llama-3.3-70b-versatile
```

> Provider / Model 僅作為**已驗證環境的紀錄**，並未寫死於應用程式架構中。
> `LLMClient` 為 OpenAI-compatible 介面，系統可指向任一相容端點（OpenAI / Groq / vLLM / Ollama 等）。

## RAG 驗證結果

### Case 1 — 有證據，正常回答

問題：**設備出現 E102 警報時，應該如何處理？**

```text
- HTTP 200
- 模型實際回答（非 fallback）
- Citation [S1] [S2] 有效
- Sources 皆對應 equipment_alarm_manual.md
```

Sources 的 `filename` / `page` / `section` / `chunk_index` / `score` / `text` 全部由後端檢索結果
組裝，**不採信 LLM 生成的 metadata**；答案中若出現不存在的 Source ID，會被 Citation 驗證移除。

### Case 2 — 完全無關問題，第一層 Threshold 拒答

問題：**台灣的首都是哪一個城市？**

```text
- Threshold 前置拒答
- Sources 為空
- generation_ms = 0
- 未呼叫 LLM
```

`generation_ms = 0` 是「未呼叫 LLM」的可觀測證據 —— 拒答是**應用程式行為**，不交由 Prompt 或
LLM 自行決定。

### Case 3 — 文件中不存在的事實

問題：**CX-500 的市場售價是多少？**

```text
- 拒答
- 沒有猜測價格
- 本次由第一層 Threshold 拒答
```

> **誠實聲明**：第二層語意拒答（context 不足時由 LLM 依 System Prompt 回固定 fallback）**已由測試覆蓋**，
> 但本次 CX-500 查詢在第一層 Threshold 就被擋下，因此**尚未以外部 Provider 實際走過第二層語意拒答分支**。

## 延遲

**單次實際樣本，非穩定 Benchmark**（單機、單次量測，受環境影響）：

```text
Retrieval：  約 98 ms
Generation：約 2047 ms
Total：      約 2145 ms
```

## 與測試的關係

本次驗證同時作為 `/api/query` 的最小 LLM smoke test：回傳 HTTP 200、有效 Citation、
Source 對應正式文件、無 `<think>` 內容。完整測試範圍與執行方式見 [testing.md](testing.md)。

## 已知限制

1. 目前是純向量 Retrieval baseline（尚未加入 keyword / hybrid / reranker）。
2. 語意相近但代碼不同的警報文件，可能干擾精確代碼查詢的排序
   （v1.1 的 identifier-aware retrieval 即針對此問題，見
   [v1.1-retrieval-optimizer-architecture.md](v1.1-retrieval-optimizer-architecture.md)）。
3. Chunking 與 Retrieval 品質仍可在後續版本調校。
4. 外部 Provider 已驗證正常回答與第一層 Threshold 拒答。
5. **第二層語意拒答尚未以外部 Provider 實際走過**（見 Case 3 誠實聲明）。
6. 目前不處理會輸出 `<think>` 的 reasoning model；已驗證模型為 `llama-3.3-70b-versatile`。

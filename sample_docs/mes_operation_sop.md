# MES 系統操作標準作業程序

> 本文件為作品集示範所建立的虛構資料，不代表任何真實公司或設備。

## 工單狀態流程

MES 工單的生命週期依序為 WAITING、READY、RUNNING、HOLD、DONE 五種狀態。
工單建立後預設為 WAITING，代表尚未備料。
當物料備妥且機台通過點檢後，工單由 WAITING 轉為 READY。
技術員在 READY 狀態下完成啟動確認，工單即由 READY 轉為 RUNNING 開始生產。
生產過程若發生異常，工單由 RUNNING 轉為 HOLD 暫停。
所有產出完成並通過檢驗後，工單由 RUNNING 轉為 DONE 結案。

## 工單啟動

工單啟動前，技術員必須逐項檢查下列欄位是否完整且正確：

1. 工單編號是否與派工單一致。
2. 物料批號是否與備料紀錄相符。
3. 機台編號是否為實際上線機台。
4. 標準工時是否已由工程單位確認。

上述任一欄位不完整時，工單不得由 READY 轉為 RUNNING。

## 狀態轉換條件

| 來源狀態 | 目標狀態 | 觸發條件 |
| --- | --- | --- |
| WAITING | READY | 物料備妥且機台點檢通過 |
| READY | RUNNING | 技術員完成啟動確認 |
| RUNNING | HOLD | 生產發生異常需暫停 |
| RUNNING | DONE | 產出完成並通過檢驗 |
| HOLD | RUNNING | 異常排除後恢復生產 |

# 生產資料介接 API 規格

> 本文件為作品集示範所建立的虛構資料，不代表任何真實公司或設備。

## 認證與 Token

介接方須先呼叫認證端點取得存取 Token。
API Token 的有效時間為 3600 秒，也就是 1 小時，逾期後必須重新取得新的 Token。
每個 Token 僅能供單一介接帳號使用，不得跨帳號共用。

## Token 規格

Token 採用 Bearer 格式置於 Authorization 標頭。
Token 字串長度上限為 512 字元，超過長度的請求將被拒絕。
系統不會在回應中重複回傳完整 Token，僅回傳前八碼作為識別。

## 上報工單進度請求欄位

呼叫工單進度上報端點時，請求主體必須包含下列欄位：

1. work_order_id：工單編號，字串，必填。
2. station_id：機台編號，字串，必填。
3. quantity：目前完成數量，整數，必填且不得為負。
4. reported_at：上報時間，ISO 8601 字串，選填。

## 回應狀態碼

| 狀態碼 | 意義 | 說明 |
| --- | --- | --- |
| 200 | 成功 | 進度已更新 |
| 401 | 未授權 | Token 無效或已逾期 |
| 422 | 欄位錯誤 | 必填欄位缺漏或格式錯誤 |
